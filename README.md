# Readest

This module runs a self-hosted Readest backend for shared reader settings and books; its persistent PostgreSQL and object storage data is kept in `data/`. The upstream Readest source is pinned as the `readest` submodule; its [Docker Compose configuration at v0.12.20](https://github.com/readest/readest/blob/v0.12.20/docker/compose.yaml) is the compatibility reference for the backend image versions here. Object storage uses PGSTY Silo, the maintained MinIO fork, because the upstream MinIO images are unavailable. Back up PostgreSQL and object storage data before upgrading. Generate production configuration with `READEST_PUBLIC_URL=https://<reader-host> READEST_S3_PUBLIC_URL=https://<storage-host> ./init.sh`.
